⚔ Hur spelar man?

En guide till äventyret — från första inloggning till sista tärningskastet.

Core Loop

1.DM vaknar — ställer 2-3 frågor om din karaktär och världen 2.Du svarar — DM väver in dina svar i öppningsscenen 3.Du agerar — skriv fritt: slå, smyg, tala, utforska 4.DM svarar — beskriver konsekvenser, NPCs, nya val 5.Tärningar — DM begär kast vid osäkerhet, du slår 6.Upprepa — storyn byggs av dina val, inget är förskrivet

Kom igång

  • Logga in med ditt användarnamn och lösenord
  • Välj äventyrstyp: Förbered (bygg värld), Importera (ladda upp filer), eller Nytt (freestyle)
  • Skapa din karaktär: välj arketyp eller skriv fritt, välj modell (DeepSeek V4 Flash / Qwen 3.8 Max)
  • Klicka "Frammana karaktär" — AI:n genererar ett fullt karaktärsark
  • Klicka "Till bordet" — DM vaknar och ställer sina frågor

Prata med NPCs

Skriv @Namn i chatten för att rikta dig direkt till en NPC.

Exempel: @Lyra Vane "Vad gör du här?"

NPC:n svarar i sin egen röst. DM kan lägga sig i med narration.

Du får autocomplete när du skriver @ — alla kända NPCs listas.

Tärningar

  • DM begär ett kast: [KAST: 1d20+4 | SMIDIGHET]
  • En knapp dyker upp i chatten — klicka för att slå
  • Tärningsbrickan längst ner är låst (🔒) tills DM begär ett kast
  • Du kan också skriva /rulla 1d20+4 direkt i chatten
  • Naturlig 20 = KRITISKT! Naturlig 1 = PATETISKT!

Mekaniska taggar (osynliga)

DM använder taggar som systemet plockar bort och omvandlar till effekter:

  • [SKADA:12] — du tar 12 skada (HP minskar)
  • [HELA:8] — du helas 8 HP
  • [XP:250] — du får erfarenhetspoäng
  • [GULD:50] — du hittar guld
  • [FÖREMÅL:Svärd|Vapen|rare] — nytt föremål i inventariet
  • [QUEST:Rädda byn|Beskrivning|100 gp] — nytt uppdrag
  • [NPC:Namn|Roll|relation] — ny NPC registreras
  • [PLATS:Stencirkeln] — platsen uppdateras

Modeller

Du kan byta AI-modell mitt i äventyret via dropdownen i topbaren.

  • DeepSeek V4 Flash — standard, snabb, reasoning-modell (tänker innan den svarar)
  • Qwen 3.8 Max — kraftfull, bra på kreativ narration
  • Qwen 3.6 Flash — snabb, används för atmosfär/ASCII-art
  • Lokala modeller — via Ollama (kräver lokal server)

Valet sparas i webbläsaren och gäller tills du byter.

Musik & Ljud

  • ♫ — musik av/på (stämningsbaserade loopar: natt, dag, strid, stad, vila, fängelsehåla)
  • 🔊 — ljudeffekter av/på (tärningar, mynt, strid, level-up)
  • Musiken byter stämning automatiskt baserat på DM:s text

Regler (D&D 5e, förenklat)

  • Kast: 1d20 + modifierare vs DC (Difficulty Class)
  • DC 10 = lätt, DC 15 = medel, DC 20 = svårt
  • HP 0 = death saves (1d20, 3 lyckade = stabil, 3 misslyckade = död)
  • XP = erfarenhetspoäng, level-up vid trösklar (300, 900, 2700...)
  • Strid: initiative → turordning → attack → skada → upprepa
  • Vila: kort vila (1h) = återställ HP, lång vila (8h) = full HP + spell slots

DM:n är den slutgiltiga domaren. Reglerna är ett ramverk, inte ett fängelse.

Tips

  • Skriv fritt — du kan göra vad som helst (försöka, inte alltid lyckas)
  • Fråga Regel-oraklet (📜) om du är osäker på D&D-regler
  • Utforska Kartan (🗺️) för att se platser och restider
  • Läs Loggboken (📜) för en sammanfattning av äventyret
  • Spara din karaktär i Valvet (🏰) för att återanvända den
  • Exportera (📦) för att ladda ner hela kampanjen som ZIP
